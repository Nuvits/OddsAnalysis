Privacy Policy

Odds Memory / Oran Hafızası · Effective 18 November 2026

Odds Memory (in Turkish: Oran Hafızası) publishes football statistics: how past matches with the same bwin odds ended. This policy covers the website nuvits.github.io/OddsAnalysis, the Instagram accounts @oddsmemory and @oranhafizasi, the YouTube channels Odds Memory and Oran Hafızası, and the publishing tool "Odds Memory Publisher".

Website visitors

  • The website has no accounts, no sign-up, no analytics, no advertising and no tracking cookies.
  • Your settings (language, odds tolerance, filters) are stored only in your own browser (local storage) and are never sent to us.
  • The website is hosted on GitHub Pages. GitHub may log technical data such as IP addresses to operate and secure the service; see the GitHub Privacy Statement.

The publishing tool and Google / YouTube data

"Odds Memory Publisher" is an automated tool used only by the owner of these channels and accounts. It creates short statistics videos and uploads them to our own YouTube channels and Instagram accounts.

  • It uses the YouTube Data API only to upload videos and set their titles, descriptions and privacy status on our own channels. It does not access, collect or store data about any other YouTube user.
  • The only Google data it keeps is an access token for our own channels, stored as an encrypted secret in our GitHub repository. It is never shared with anyone.
  • The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • The tool uses YouTube API Services. See the Google Privacy Policy and the YouTube Terms of Service.
  • Access can be revoked at any time on the Google security settings page.

Instagram / Meta data

The tool uses the Instagram API only to publish posts and Reels on our own Instagram accounts. It does not read messages, comments or data of other Instagram users. Meta's handling of data is described in the Instagram Privacy Policy.

Data we do not collect

We do not sell, rent or share personal data, and we do not use it for advertising. We do not knowingly collect data from anyone under 18.

Match data

Results and odds come from football-data.co.uk. They contain no personal data.

Changes and contact

If this policy changes, the new version will be published on this page with a new effective date. Questions: oddsmemory@yahoo.com.
